3. GITHUB-REPOSITORY ANLEGEN
----------------------------
Auf github.com:

A) Oben rechts auf "+" → "New repository"
B) Repository-Name z. B.:
   40-tage-fuer-dich

C) "Public" wählen.
   Hinweis: Eine normale kostenlose GitHub-Pages-Seite ist öffentlich erreichbar.

D) Repository erstellen.

4. DATEIEN HOCHLADEN
--------------------
Im neuen Repository:

"Add file" → "Upload files"

Dann den INHALT dieses Ordners hochladen, also:
- index.html
- style.css
- script.js
- inhalte.js
- manifest.webmanifest
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- favicon.png
- bryan-adams-geschenk.png
- Ordner "bilder" mit tag01.jpg bis tag40.jpg

WICHTIG:
Nicht den äußeren Ordner als zusätzliche Ebene hochladen.
"index.html" muss direkt oben im Repository liegen.

Anschließend unten:
"Commit changes"

5. GITHUB PAGES AKTIVIEREN
--------------------------
Im Repository:

Settings → Pages

Bei "Build and deployment":
Source: Deploy from a branch

Branch:
main

Ordner:
(root)

Dann "Save".

Nach kurzer Zeit zeigt GitHub dort die Adresse deiner Webseite an, typischerweise:

https://DEIN-GITHUB-NAME.github.io/40-tage-fuer-dich/

DAS IST DER EINE FESTE LINK FÜR ALLE 40 TAGE.

9. DATENSCHUTZ
--------------
Die Seite enthält:
<meta name="robots" content="noindex,nofollow,noarchive">

Das bittet Suchmaschinen darum, die Seite nicht zu indexieren.
Es ist aber KEIN echter Zugriffsschutz.

Die GitHub-Pages-Adresse und die Bilder sind technisch öffentlich abrufbar.
Deshalb keine intimen oder wirklich sensiblen Fotos verwenden.
